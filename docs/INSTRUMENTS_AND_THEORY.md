### 1.2 键数与乐器内部结构

- **键数由 type 决定**:type2 → 8 键、type4 → 4 键、其余 15 键
  (`instrument+76`,运行时值在 `instrument+75128`,开菜单刷新)。
- 关键字段速查(偏移见 `mod/src/Offsets.h`):

| 偏移 | 含义 |
|---|---|
| +76 / +77 / +78 | 乐器类型 / 变体 / 音高(sub) |
| +79 | 延音标志(1 = 延音乐器; 钢琴类为 0) |
| +80 | AvatarSound* 延音登记处(bank) |
| +0xA8 | 姿态控制器 —— **只在乐器界面打开时存在** |
| +47248 | 静音闸(≠0 时 OnStart 不发 RPC, 乐谱界面打开时置位) |
| +68108 | 环境加载标志(signed char < 0 = 在世界内, 可弹) |
| +47200 | 玩家 id 异或对(自异或还原 playerId) |

- **弹奏只要求"已装备 + 在世界内"**, 不需要打开乐器界面; 但**动画**需要
  界面开着(姿态控制器存在), `piano.setAnim(true)` 开(带空指针护栏)。

### 1.3 延音系统(编曲最重要的规则)

- **延音乐器** = type 1 全部 + type 3 全部 + type0 的 sub9/11。
  它们的声音事件**循环播放直到收到 note-off**; 不停就一直响。
- **自然衰减乐器**(钢琴/竖琴/铃/鼓类)响约 1 秒自己停, 无延音句柄,
  **无法中途掐掉**(急停也留 ≤1s 余音)。
- 时值控制: 延音乐器必须给 `durMs`(或吃 500ms 默认自动停);
  `P.skyD` 事件表带真实时值, `P.sky` 不带(适合衰减类)。
- **延音并发上限 5**(游戏原生, `NumSustainNotesPlaying(bank) > 4` 时丢音)。
  编曲实践: 同时延音 ≤4。衰减类不受限。
- note-off = 本地 `StopSustainNote(bank, note, 1)` + 停止 RPC(+0x40=1, +0x42=1),
  远端同步停。

### 1.4 音量与角色定位(编曲经验)

- 音量最突出: 钢琴 → APPiano → 吉他类; 最收敛: 竖琴、卡林巴、钢片琴。
- 经验配比: **主旋律**(长笛/小提琴/APPiano)+ **和声垫**(竖琴/大提琴/陶笛)
  + **低音**(低音提琴)+ **点缀**(钢片琴/卡林巴)。
- 伴奏音量要"退后": 用户实测裁决 —— 钢琴当伴奏太抢, 换竖琴;
  极光带人声不能用; 管乐主旋律 + 软音色伴奏是舒适区。

## 二、15 键乐理

### 2.1 键盘结构

15 键 = **C4~C6 两个八度的 C 大调全白键,没有黑键**。
音高表(0x141E70F20)为半音序列 `0,2,4,5,7,9,11,12,14,16,17,19,21,23,24`。

| 键 | 音 | 唱名 | | 键 | 音 | 唱名 |
|---|---|---|---|---|---|---|
| 0 | C4 | 1 | | 8 | D5 | 2' |
| 1 | D4 | 2 | | 9 | E5 | 3' |
| 2 | E4 | 3 | | 10 | F5 | 4' |
| 3 | F4 | 4 | | 11 | G5 | 5' |
| 4 | G4 | 5 | | 12 | A5 | 6' |
| 5 | A4 | 6 | | 13 | B5 | 7' |
| 6 | B4 | 7 | | 14 | C6 | 1'' |
| 7 | C5 | 1' | | | | |

换算: `键 = 唱名数字 - 1 + 高音点×7`(lib 的 `P.deg`); MIDI 音高
`p` → 键: 度数 `deg = 白键序[p%12]`,`键 = (p//12 - 5)×7 + deg`,黑键就近吸附。

### 2.2 调性: 只有 C 大调和 A 小调

15 键只能原样演奏 **C 大调及其关系小调 A 小调**(白键集合相同)。
其他调的歌必须转调:

- **转调 = 全体平移半音**, 目标是把原调音阶 7 个音级全部落到白键。
  对任何大调小调, 这样的平移总存在(大调 tonic→C; 小调走关系大调 tonic→C)。
- 平移**不改变大小调性** —— 原曲大调转出来还是大调。若听起来"变小调了",
  一定是转调量选错(音阶被怼上黑键再吸附, 三级五级被压平), 不是转调本身。
- **调性检测必须排除 GM 鼓轨**(通道 10): 打击音符音高无调性, 会把
  直方图搅平、选出错误的旋转(反乌托邦实测: 鼓轨污染把 F 大调错判成 +5
  以外的旋转, 大调听成小调)。
- 原曲的**半音装饰音**(蓝调音/经过音)吸附规则: 就近白键, 优先向下。
- **RPC 里没有音高字段** → 已弹出的音无法变调; 变调只能在转谱时做
  (音级平移)。半音变调(如 C→C#)在物理上不可能同步到远端。

### 2.3 和弦指法

三和弦在 15 键上的标准封闭位(根音-三音-五音, 全在低八度):

```text
C  = 0,2,4    F  = 3,5,7    G  = 4,6,8    A5/Aug…
Dm = 1,3,5    Am = 5,7,9    Em = 2,4,6
Bdim = 6,8,11(少用)         G7 ≈ 4,6,8(+13)
```

- **sus2 空五度**(`F = 3,4,7`)用于还原原曲的悬浮感(His Theme 实战)。
- 转位: 把最低音 +7 抬进高八度即可(如 C/E = 2,4,7)。
- 低音走根音-五度交替(`b1=根, b2=五度`, 见 lib 的 `P.CH`)。
- 键盘只有两个八度, **低音和和弦必然同区** —— 低音用低八度音色的提琴类
  (音色自带下沉), 和弦用衰减类拨弦, 靠音色分层而不是音区分层。

### 2.4 音域规划(编曲核心功)

15 键只有两个八度, 多声部必然拥挤。分层原则:

```text
键 0-4   低音区: 低音提琴/大提琴 根音长音
键 4-9   中音区: 和弦垫(竖琴琶音/提琴拉音)
键 7-14  高音区: 主旋律(长笛/小提琴/钢琴) + 钢片琴点缀
```

- **统一压缩**(midi2sky `--compress`): 全曲一条规则折进 C4~C6 ——
  保住声部相对音区, 主旋律若在范围内则零失真。**默认用这个**。
- **按声部独立选八度**: 各声部找自己最优八度 —— 折叠最少但**会打乱
  声部相对关系**(实测教训: 低音被抬两八度后调性听感错乱)。
- **`--lift "2:+1"`**: 指定声部抬/降八度后再压缩 —— 高音区不够亮/太尖
  时的微调钮。先抬后折, 永不越界。
- 八度折叠(wrap)会让跨八度旋律在折点跳变 —— 旋律声部尽量保持在
  范围内(选调时让旋律中位音落在键 7~11 最舒服)。

### 2.5 节奏与时值

- mod 全链路毫秒制: `Q = 60000/BPM`(四分音符 ms); 3/4 小节 = 3Q,
  4/4 = 4Q; 八分 = Q/2, 十六分 = Q/4。
- 简谱"拍位制": `"唱名@拍位"`, 拍位 = 小节内起始拍(0/0.5/.../3.5),
  时值 = 到下一音的距离(见 `P.rows`)。
- Sky Studio / MIDI 转谱: 时间轴毫秒直读, 和弦 = 同刻多音,
  十六分装饰按半拍再细分。
- 密度预算: **RPC 广播安全线 ≈ 15 音/秒**(实测 250+ RPC 稳定,
  但礼貌起见按此预算); 本地音墙(noRpc)可到 30/秒, 再高 FMOD 自己削顶。
- 延音声部并发 ≤4; 长音时值给 `×0.9` 留气口, 避免下一音顶掉上一音。

### 2.6 鼓轨(GM 通道 10)处理

- GM 鼓音符的"音高"是**鼓件编号**(36 底鼓/38 军鼓/42 踩镲...), 不是旋律音。
- TR909 = 8 个垫 = 8 种鼓件。直接把鼓轨当旋律映射会让所有鼓件塌到
  1-2 个键上(八度折叠所致) —— 听起来"没有鼓"。
- 正确做法(midi2sky `--remap-pads "0"`): 按**打击频率排名**把不同鼓件
  分到不同垫; `--drum-drop 1` 扔掉最高频的踩镲墙(占 90%+ 击数),
  留底鼓+军鼓骨架; 配 `--prune 15` 控制密度。
- 鼓一律 **noRpc 本地**(自己有鼓点, 远端听干净合奏)。

### 2.7 转谱流水线(把以上规则串起来)

```text
任意 MIDI
  → midi2sky.py: 排除鼓轨选调(平移到 C 大调) → 分声部(轨/通道/音域切带)
  → 黑键吸附白键 → 统一压缩 C4~C6(--compress, 可配 --lift 微调)
  → 鼓轨映射 TR909 垫(--remap-pads/--drum-drop)
  → 密度剪枝(--prune) → 本地/广播分账(--local-chans)
  → songs/*.lua (P.sky / P.skyD 事件表)
  → checksong.py 校验(键位/时值/分块) → 游戏内贴 lib.lua + 歌
```

其他谱源: Sky Studio 社区谱(`sky2lua.ps1`, "NKeyM" 的 M 即键号)、
简谱截图(手转"唱名@拍位" + `P.rows`)、五线谱 PDF/MusicXML
(图鉴 01.110-112 系列工具先转 MIDI)。

### 2.8 踩坑记录(规则背后的血泪)

| 坑 | 规则 |
|---|---|
| `local` 是 Lua 关键字 | 选项名永远用 `noRpc`, 不用 `local` |
| `lua_toboolean(缺失索引)` 是 UB | 读可选参数一律 `lua_tointegerx`(isnum 判空) |
| 鼓轨参与调性投票 | 调性检测排除 ch10 |
| 按声部独立选八度 | 打乱相对音区 → 用 `--compress` 统一压缩 |
| 姿态控制器空指针 | 动画只在乐器界面开着时可用, 调用前查 +0xA8 |
| PowerShell 5.1 读无 BOM UTF-8 | .ps1 带中文必须写 BOM |
| 极光人声采样 | 编曲禁用 MicAurora |
| 钢琴当伴奏 | 音量太抢, 伴奏用竖琴/卡林巴 |
